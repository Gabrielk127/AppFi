## Descrição

AppFi é um aplicativo de controle financeiro desenvolvido com **React Native** e **TypeScript**. Este projeto está em construção e serve como uma plataforma para adquirir experiência em desenvolvimento de aplicações móveis. Com o AppFi, você pode cadastrar receitas e despesas, criar objetivos financeiros como a compra de um carro novo e acompanhar a evolução do seu patrimônio através de gráficos intuitivos.

## Tecnologias Utilizadas

- **React Native**
- **TypeScript**
- **Expo**
- **Expo Router**

## Funcionalidades

- **Cadastrar Receitas:** Adicione suas receitas financeiras de forma organizada.
- **Cadastrar Despesas:** Controle suas despesas para um melhor gerenciamento financeiro.
- **Controle Financeiro:** Visualize o saldo total e o desempenho das suas finanças.
- **Visualizar Métricas:** Acompanhe suas finanças através de gráficos intuitivos.
- **Criar Objetivos Financeiros:** Estabeleça e acompanhe objetivos financeiros, como a compra de um carro novo.
- **Controle de Múltiplas Contas:** Gerencie várias contas bancárias em um só lugar.

## Instalação

Siga os passos abaixo para configurar o ambiente e rodar o projeto:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/AppFi.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd AppFi
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Execute o projeto:
   ```bash
   expo start
   ```

## Uso

Para utilizar o aplicativo, siga as instruções abaixo:

1. **Cadastro de Receitas e Despesas:** Acesse a seção de receitas e despesas para adicionar suas transações financeiras.
2. **Visualização de Gráficos:** Navegue até a seção de métricas para visualizar gráficos de desempenho financeiro.
3. **Definição de Objetivos:** Utilize a funcionalidade de objetivos para criar e monitorar metas financeiras.
